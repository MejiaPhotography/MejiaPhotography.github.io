# Mejia Photography

Website for mejia-photography.com (single-page static site).

## Structure
- `index.html`: the whole site (edit colors/fonts in the `:root` block at the top)
- `images/portfolio/`: portfolio photos (`portraits-01.jpg`, `graduation-01.jpg`, `pets-01.jpg`, `realestate-01.jpg`, `outdoors-01.jpg`, ...)
- `images/hero.jpg`: top banner photo (optional)
- `images/about.jpg`: About section photo (optional)

Any photo saved with a matching name replaces its gray placeholder automatically.
